# TimeSync Pro

An interactive global meeting time zone and fairness planner with support for **India (IST)**, custom working hours, dark/light theme, 12/24h clocks, DST shift checks, weekly heatmaps, Google/Outlook calendar links, `.ics` export, JSON backup/restore, and a first-time arrow walkthrough guide.

## Files Included
- `index.html` — Application structure, footer links, info modals, and walkthrough overlay
- `style.css` — Light/dark themes, responsive layout, timeline strips, heatmap, and animated guide pointer dot
- `app.js` — Time zone math, fairness scoring, DST checks, calendar export, and first-time device guide
- `favicon.svg` — Custom globe + meeting indicator SVG favicon
- `data/city-aliases.json` — City-to-IANA time zone mapping including India (IST)
